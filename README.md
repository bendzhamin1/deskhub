# DeskHub

Расширение для Chrome, которое заменяет страницу новой вкладки на рабочий стол
с папками и закладками — по механике главной страницы Яндекс Браузера.

Иконки сайтов подтягиваются автоматически вместе с фирменным цветом подложки,
папки и плитки можно настроить вручную, а весь набор синхронизируется между
устройствами через аккаунт Chrome.

## Возможности

- Папки и закладки на новой вкладке, drag & drop с живой сортировкой
- Автоматические логотипы сайтов с определением бренд-цвета плитки
- Ручная настройка плиток: название, адрес, свой логотип, свой цвет
- Настройка папок: название, свой цвет с регулируемой прозрачностью
- Свои обои рабочего стола
- Экспорт и импорт конфигурации в файл — можно передать свой набор другому
- Темы, три размера карточек, настройка свечения и прозрачности, часы
- Поиск через вашу поисковую систему по умолчанию в Chrome, с подсказками из закладок и истории

## Установка

Из Chrome Web Store — ссылка появится здесь после публикации.

Вручную из исходников:

1. Скачать или клонировать репозиторий
2. Открыть `chrome://extensions`
3. Включить режим разработчика
4. Нажать «Загрузить распакованное расширение» и выбрать папку репозитория

## Синхронизация

Данные хранятся в `chrome.storage.sync` и синхронизируются между компьютерами,
где выполнен вход в один аккаунт Chrome. Отдельная регистрация не нужна.

Состояние режется на части по нескольким ключам, чтобы обойти ограничение
в 8 КБ на ключ и использовать всю квоту синхронизации — это сотни закладок.
Обои хранятся локально и не синхронизируются: изображение слишком велико
для квоты sync.

## Разработка

Расширение написано на чистом JavaScript без сборки и зависимостей.
`js/storage.js` отвечает за данные и хранилище, `js/newtab.js` — за интерфейс.

Для локального просмотра нужен HTTP-сервер, потому что страница использует
ES-модули:

```bash
python -m http.server 8755
```

Затем открыть `http://localhost:8755/newtab.html`. Вне Chrome расширение
работает на `localStorage`, поэтому интерфейс можно смотреть в обычной вкладке.

## Разрешения

- `storage` — хранение закладок и настроек
- `search` — поиск через систему по умолчанию, выбранную в настройках Chrome

Расширение не собирает данные и не отправляет их куда-либо. Поисковый запрос
уходит только в вашу поисковую систему по умолчанию, когда вы сами его вводите.
